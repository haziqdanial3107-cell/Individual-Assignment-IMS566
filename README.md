# UniEvent -- IMS566 Project

## Project Description

UniEvent is a responsive university sports event management prototype. Students
can discover campus sports, register for activities, and review their upcoming
registrations. Administrators can create and manage sports event listings,
including their photos, and review attendance.

## Features

- Login and student registration with validation and clear error feedback.
- Searchable sports event listings with event photos.
- Sample demo attendees to populate event counts and admin attendance views.
- Student dashboard with registration and upcoming-event summaries.
- Responsive data grids for event listings, admin event management, and attendance.
- Admin tools for managing events and reviewing participants. Event photos can
  use direct image URLs or files saved in the project `images/` folder.
- Meaningful Chart.js visualizations of registrations per sport event and seat
  availability.
- Responsive layouts and consistent navigation.
- Chart and Graph will appear when login with admin email.

## Test Login

- **Admin:** `admin@univent.edu` / `admin123`
- **Student:** `student@univent.edu` / `student123`
- **User:** User or student can create their own account.



## Frameworks and Libraries

- HTML5, CSS3, and vanilla JavaScript
- Bootstrap 5.3.3 for responsive form components
- Chart.js 4.4.1 for dashboard visualizations
- Browser Local Storage for prototype data persistence

Bootstrap and Chart.js are loaded from jsDelivr CDNs, so an internet connection
is needed for those libraries.

# IMS566 -- Advanced Web Design Development and Content Management

## Individual Assignment 

### 1. Objective of the Project

This project requires students to demonstrate their understanding of
advanced web design principles and content management concepts by
developing a functional web application interface. Students must apply
the theories, techniques, and tools learned in lectures to build a
small-scale but professional web application prototype.

### 2. Project Weightage

This individual project carries **20%** marks.

### 3. Project Scope and Requirements

Student must design and develop a web application interface using
any suitable theme/system (e.g., student portal, e-commerce, library
system, task manager, internship tracker, etc.).

#### 3.1 Authentication Page (Login/Register)

-   Authentication can be simulated with hardcoded credentials (no
    database required).
-   Provide a clear user interface with error feedback (e.g., invalid
    username/password).

#### 3.2 Navigation Menu

-   Provide a consistent menu/navigation bar that links all pages.
-   Use responsive design so the website works on desktop and mobile.

#### 3.3 Dashboard Page

-   Provide a landing page after login that displays key information or
    a summary.
-   Include at least one visual element (e.g., a chart).

#### 3.4 Data View Pages (Minimum 2)

-   Include at least two pages displaying different datasets (e.g., a
    list of users, products, tasks, or articles).
-   Use tables, lists, or grids to present data clearly.

#### 3.5 Data Visualisation Component

-   Include at least one chart, graph, or infographic using Chart.js,
    ApexCharts, or a similar library.
-   The visualisation must be meaningful, not random.

### 4. Technical Requirements

-   **Front-end framework:** Bootstrap 5, Tailwind CSS, and
    another modern framework.
-   **Code organisation:** HTML, CSS, and JavaScript be
    structured properly and commented.
-   **Responsive design:** Pages must be mobile-friendly.
-   **Content management:** Show awareness of content organisation,
    including titles, metadata, and structured sections.

### 5. Deployment

1.  Upload the project repository to GitHub.
2.  Publish the project using GitHub Pages.
3.  Submit both:
    -   GitHub Pages live website link (e.g.,
        `https://username.github.io/projectname/`)
    -   GitHub repository link.

### 6. Deliverables

1.  Live website link (GitHub Pages).
2.  GitHub repository link (must contain the source code).
3.  A documentation file (`README.md`) containing:
    -   Project title and description.
    -   Features included.
    -   Instructions to test login.
    -   Frameworks/libraries used.
